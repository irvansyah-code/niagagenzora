# Versi Statis Siap GitHub Pages

## Hasil yang dibuat
- Satu halaman statis dengan bagian Beranda, Produk, Pelanggan, Artikel, Kontak, Masuk, dan Daftar.
- Header memakai nama **niagagenzora.com**, tombol Indonesia/English, pencarian, dan menu HP.
- Video YouTube, banner berganti otomatis, keunggulan produk, footer, serta ikon media sosial tetap tersedia.
- Semua teks utama berubah langsung saat tombol **ID** atau **EN** dipilih.

## Susunan sederhana
```text
niagagenzora-github/
├── index.html
├── style.css
├── script.js
└── img/
    ├── promo-1.jpg
    ├── promo-2.jpg
    └── promo-3.jpg
```

## Cara kerja
- Navigasi berpindah ke bagian terkait dalam satu halaman, sehingga tidak memerlukan sistem halaman khusus.
- `script.js` menangani menu HP, pilihan bahasa, pencarian, banner, serta formulir tampilan.
- Pilihan bahasa tersimpan di browser pengunjung.
- Tidak ada sistem masuk atau penyimpanan data; formulir tetap berupa tampilan, sesuai kondisi situs sekarang.

## Publikasi
- Siapkan folder sumber bersih dan berkas ZIP agar mudah diunggah ke GitHub.
- Struktur ini bisa dipublikasikan langsung melalui GitHub Pages tanpa proses pembuatan tambahan.
- Pratinjau Lovable tetap dipertahankan pada teknologi proyek yang didukung, sementara paket statis menjadi versi sederhana untuk GitHub Pages.

## Pemeriksaan
- Uji desktop dan HP, pergantian ID/EN, pencarian, menu, carousel, tautan bagian, serta pemuatan semua gambar.
